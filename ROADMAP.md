# Roadmap

The project prioritizes a reliable research pipeline over additional exchange
integrations.

## Near Term

- Publish a small, legally reviewed sample dataset.
- Improve the public Python API and command-line interface.
- Add more synthetic fixtures and causal feature tests.
- Document reproducible benchmarks for DRBs versus time bars.

## Later

- Support additional information-bar types through the public API.
- Add exchange connectors behind a stable connector interface.
- Publish versioned releases and benchmark reports.
- Improve optional GPU optimization workflows.

Contributions are welcome. See `CONTRIBUTING.md` for development conventions.
